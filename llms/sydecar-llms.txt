# Sydecar

> Sydecar is a deal execution platform for venture investors that automates the operational back office of Special Purpose Vehicles (SPVs) — banking, compliance, KYC/AML, contracts, capital calls, and investor reporting. The Sydecar API lets developers run funding processes programmatically on Sydecar's legal, banking, and compliance rails, with the SPV as the foundational unit.

## API

- [Sydecar API Docs](https://api-docs.sydecar.io/): Developer documentation portal (password-protected) for the Sydecar API.
- [Overview and Guide](https://api-docs.sydecar.io/docs/resources/guide/): Getting-started guide covering authentication and environments.
- API host: https://api.sydecar.io
- Authentication: Bearer token on the HTTP Authorization header. API keys are tied to a single API user account. Production tokens are issued on sign-up; sandbox/staging tokens are provided on request.
- Environments: one production environment (tied to ledger and fund management for your SPVs) plus any number of staging (development) environments.
- Core resources: SPV, Subscription, Document, Person.
